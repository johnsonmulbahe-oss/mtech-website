1. Getting Started

Open M-TECH: Use the official M-TECH link, QR code, or installed home-screen application.
Install on iPhone/iPad: Safari → Share → Add to Home Screen.
Install on Android: Chrome → menu → Install app / Add to Home Screen.
Updates: The installed app uses the same live application. Normal updates do not require a new customer link or QR code.
If an older version remains visible, close the app completely and reopen it once while connected to the internet.

2. Customer Request Form

Choose the main service category and the exact service/problem from the available options.
Add a clear description and photos, voice or short video where useful.
Enter contact information and submit once. Keep the reference number shown after successful submission.

3. Management Dashboard

Review customer requests, jobs, quotations, invoices, staff, appointments and business activity from the dashboard.
Use the application Back control to return to the previous M-TECH screen. The Back control is fixed; the AI bubble may be moved so it does not cover records.
Use Refresh when you need the newest data immediately. Major modules progressively load to improve speed.

4. Customer Requests

Open a request to review customer details, exact problem, attachments and status.
Move requests through the appropriate workflow and create quotations or work orders from the original request where possible.

5. Jobs / Work Orders

Create jobs from customer requests whenever possible, assign the correct staff/technician and maintain job status and activity history.
Use before/after evidence, costs and completion information where applicable before closing a job.

6. Quotations, Invoices & Payments

Prepare quotations from confirmed requirements and verify currency, totals, validity and customer details before sharing.
Create invoices for approved work and record payments against the correct invoice while preserving remaining balances.
Use generated document links/print views instead of screenshots for professional customer documents.

7. Customers, Organizations, Staff & Leadership

Maintain clean customer and organization records to reduce duplication.
Staff/leadership profiles may include photos, role/title, department, employment type/status, contacts, qualifications, documents, compensation arrangements, schedules and authorized notes.

8. Appointments, Reminders, Expenses & Assets

Use appointments for visits, installations, meetings and training; use reminders for follow-ups and deadlines.
Record expenses with correct date, description, category, currency and amount. Record durable business property in Assets instead of ordinary expenses.

9. Services & System Settings

CEO/Admin controls company identity, service categories, exact services, pricing/packages, business defaults, document settings, customer-portal settings and system preferences.
Sensitive security and financial controls should remain CEO/Admin controlled.

10. QR Sharing & Distribution

Use Sharing QR and QR Distribution Register to create, print, distribute and track M-TECH QR campaigns.
Register approved locations, placement details and campaign information so distributed QR materials remain accountable.

11. User Access, Email Login & Password Recovery

New internal users may request access through the CEO-generated QR invitation process. Scanning the QR does not grant access until the CEO approves the request.
Approved users can use email/password and supported secure email sign-in methods.
Forgot Password: enter the approved account email on the login screen, tap Forgot Password, open the secure recovery email, choose a new password and return to M-TECH.
The CEO Password Recovery Center may send a secure reset link to an approved worker without seeing or setting that worker's password.

12. Problem Solving, Innovation & Community Hub

Solve a Problem: create a structured workspace for a real challenge.
Innovation Lab: move ideas through problem definition, research, proposed solution, prototype, testing and implementation.
Knowledge Bank: preserve approved solutions for future reuse.

13. Skills & Learning Center

Use structured M-TECH learning paths, course handbooks, quick-study summaries and practical projects.
Connect learning with Innovation Lab work so technology education leads to practical problem solving.

14. Education & Technology Center

The Education & Technology Center is M-TECH's dedicated digital learning library built around the slogan “Technology is our passion, Education is our life…”.
Authorized users can search technology resources, open supported PDFs, bookmark resources and continue reading from saved progress.
The CEO Upload Center can add large technology PDF notes/books into the private Education Library, organize them by subject, learning level and access level, and make them available to approved readers.
The library is designed for very large learning resources, including long professional/college notes and books, while files remain in secure cloud storage rather than inside the website code repository.

15. Application Technology Stack & Supporting Resources

HTML5: provides the structure of the M-TECH web pages, forms, dashboards, documents and application screens.
CSS3: provides responsive layouts, branding, mobile/iPhone safe-area behavior, glass-style interfaces, printing rules and device-adaptive presentation.
JavaScript (ES6+): powers application logic, interactive forms, dashboards, authentication flows, search, PWA behavior, AI/user-interface controls, offline/resilience features and Supabase communication.
SQL / PostgreSQL: powers the M-TECH business database, relational records, functions, policies, audit-related controls and secure server-side data logic.
JSON: is used for structured configuration, metadata, permissions, application settings, API payloads and flexible data fields.
Progressive Web App technologies: Web App Manifest plus JavaScript Service Worker provide installable app behavior, caching/update management and improved mobile use.
Supabase: provides PostgreSQL database hosting, Authentication, private/public Storage, Row Level Security, database functions/RPCs and supporting backend services.
Supabase JavaScript client: securely connects the browser application to approved authentication, database, storage and RPC operations.
Git & GitHub: provide source control, revision history and managed application code hosting. GitHub Pages publishes the live M-TECH frontend/PWA.
HTTPS/TLS: protects web traffic between devices and hosted services while the application is accessed over the internet.
Cloudflare Pages: is documented as an available/optional web deployment resource where appropriate; it is not required for every live M-TECH application route.
Supporting Python tooling: Python is used where appropriate for document/data processing and generation tasks that support the project rather than as the primary browser application language.
ReportLab / DOCX / PDF tooling: supports creation of professional PDF and Word-compatible documentation and project artifacts where required.
Markdown: supports technical documentation, structured notes, handbooks and portable text-based project content.
The primary live application is a web/PWA system built mainly with HTML, CSS, JavaScript and PostgreSQL/Supabase. Supporting tools are documented separately so the guide does not falsely describe support utilities as the main application runtime.

16. QR Permission & Outreach Center

Use the QR Permission & Outreach Center before placing M-TECH posters/QR materials on property controlled by a college, school, church, company, NGO, government office, hospital, community organization or other institution.
Choose the organization type, enter the organization/recipient details, proposed number of QR placements, approved locations and requested duration.
The system generates both a professional Permission Request Letter and a structured QR Outreach Implementation Plan.
Save drafts, copy the document, download a Word-compatible copy, or Print / Save PDF. Once permission is granted, record the campaign in the QR Distribution Register.
M-TECH should respect the receiving organization's decision and any limits on advertising, placement, duration, privacy, campus/property access or removal.

17. Device & Connectivity Guidance

The live system is designed for iPhone, Android, tablets, laptops and desktop browsers.
If login reports Failed to fetch, check internet connectivity, VPN/proxy, browser restrictions, DNS/firewall and retry.
If a button appears stuck, allow the page to finish loading, tap once, confirm connectivity, then capture a screenshot if the problem continues.

18. CEO Security & Administration

Never share the CEO password. Create separate authorized accounts for staff or other approved users.
Use role-based access, approval controls, audit history, activation/suspension and emergency controls where appropriate.
Permanent deletion of protected records remains a CEO-controlled action where implemented.
