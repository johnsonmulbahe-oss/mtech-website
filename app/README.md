# M-TECH Digital Operations Application v2

This directory is reserved for the standalone M-TECH technology-management web application.

It is independent from the public M-TECH marketing website at the repository root.

Deployment status: preparation in progress.

Production stack target:
- Static/PWA hosting: free HTTPS hosting
- Cloud database/auth/storage: Supabase Free
- Customer request portal with photo uploads
- CEO/staff dashboard
- Quotations, invoices, payments and digital receipts
- Appointments and notifications
- Staff/HR records and documents
- Training and verifiable certificates
- QR customer request access

Do not place Supabase service-role keys, SMS provider secrets, WhatsApp secrets, email API secrets, passwords or other private credentials in this repository.
